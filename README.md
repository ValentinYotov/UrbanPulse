# UrbanPulse

UrbanPulse е уеб платформа за гражданско докладване, анализ и визуализация на инциденти и проблеми в градската среда. Проектът цели да даде възможност на гражданите да докладват опасности, произшествия и инфраструктурни проблеми, да ги визуализират на карта, да анализират статистики и да използват AI асистент за въпроси, свързани с градската среда.

## Основна идея и цели
UrbanPulse е създаден с мисията да направи градската среда по-безопасна, прозрачна и интерактивна чрез:
- Лесно докладване на инциденти и проблеми от граждани
- Визуализация на всички инциденти на интерактивна карта
- Достъп до статистики и анализи за по-добро разбиране на градските проблеми
- Използване на AI асистент за въпроси, свързани с градската среда

---

## Технологии
### Frontend
- **HTML5, CSS3, JavaScript (ES6+)**
- **Leaflet.js** – за визуализация на карта и маркери
- **GSAP, Anime.js, Vanta.js** – за анимации и визуални ефекти
- **Chart.js** – за визуализация на статистики
- **Font Awesome** – икони
- **Firebase Web SDK** – за автентикация, база данни и storage

### Backend
- **Firebase Cloud Functions (Node.js)** – за AI асистент и backend логика
- **OpenAI API** – интеграция с GPT модел за AI чат

### Cloud
- **Firebase Authentication** – регистрация и логин на потребители
- **Cloud Firestore** – съхранение на инциденти и потребителски данни
- **Cloud Storage** – съхранение на снимки към инциденти

## Функционалности
- **Регистрация и вход** – чрез Firebase Authentication
- **Докладване на инцидент** – форма с тип, описание, локация (карта), снимки
- **Визуализация на карта** – всички инциденти с цветни маркери по тип
- **Статистики и анализи** – графики и списъци по категории
- **AI асистент** – чат с GPT модел за въпроси, свързани с градската среда
- **Локално съхранение на чатове** – за по-добро UX
- **Logout** – излизане от профила

## Описание на основните страници
### index.html (Начална страница)
- Представя проекта, основните му възможности и навигация към всички секции.
- Съдържа секция с услуги (докладване, карта, статистика, AI).

### report.html (Докладване на инцидент)
- Форма за докладване: избор на тип (Danger, Accident, Infrastructure Issue), описание, избор на локация на карта (Leaflet), добавяне на снимки.
- При submit: данните се записват във Firestore, снимките (ако има) – в Storage.
- Валидация и визуална обратна връзка при успех/грешка.

### map.html (Карта с инциденти)
- Визуализира всички инциденти от Firestore на карта (Leaflet) с цветни маркери по тип.
- Popup с детайли за всеки инцидент.
- Легенда за типовете инциденти.

### statistics.html (Статистики и анализи)
- Използва Chart.js за графики по тип инцидент.
- Списъци с инциденти по категории.
- Анимации и визуални ефекти.

### ask_ai.html (AI асистент)
- Чат интерфейс с GPT модел (чрез Cloud Function).
- Локално съхранение на чатове и история.
- UX подобрения: typing indicator, анимации.

### login.html / signup.html
- Форма за вход/регистрация чрез Firebase Authentication.
- Валидация и обработка на грешки.

### about.html
- Информация за проекта, екипа, мисията и контакт.

## Backend (Cloud Functions)
- **functions/index.js** – Cloud Function `askAI`:
  - HTTP endpoint, който приема POST заявки с user message.
  - Използва OpenAI API (GPT-3.5-turbo) за генериране на отговор.
  - Връща отговора като JSON.
  - CORS е разрешен за всички домейни (може да се ограничи при нужда).
  - Логва заявките и отговорите за дебъг.

## Настройка и стартиране
### 1. Клониране на репото
```sh
git clone <repo-url>
cd UrbanPulse
```

### 2. Настройка на Firebase
- Създай проект във [Firebase Console](https://console.firebase.google.com/)
- Активирай **Authentication**, **Firestore Database**, **Storage**
- Копирай конфигурацията във UrbanPulse/js/firebase-config.js
- (По желание) Използвай .env файл и не качвай ключове публично!

### 3. Инсталиране на зависимости за Cloud Functions
```sh
cd functions
npm install
```

### 4. Деплой на Cloud Functions
```sh
firebase deploy --only functions
```

### 5. Стартиране на frontend (локално)
- Можеш да отвориш UrbanPulse/html/index.html директно или да използваш live server разширение.
- За production – деплой на Firebase Hosting или друг статичен хостинг.

## Сигурност и добри практики
- **Никога не качвай API ключове публично!** Използвай .env и .gitignore.
- Ограничи API ключовете по домейн и по разрешени API.
- Настрой правилата на Firestore и Storage:
  - За разработка: allow read, write: if true;
  - За продукция: allow read, write: if request.auth != null;
- Следи за злоупотреби и квоти в Google Cloud Console.
